RUN VIA LOCAL SERVER

Browsers block API calls from file://. Serve via localhost instead:

Option 1 — Python (recommended):
Open terminal in the JARVIS.html folder:
python -m http.server 8080
Then open: http://localhost:8080/JARVIS.html

Option 2 — VS Code:
Install "Live Server" extension → right-click file → Open with Live Server

Option 3 — Node:
npx serve . then open the URL shown
